# WatchButler — personal butler

- Tasks, calendar, journal; reminders via cron; job-search tracking (applications, interviews, platforms).
- Cross-agent memory: reads every agent's chat history through one search script; handoff files between agents.
- Runs the hourly script watcher that feeds new channel scripts to the storyboard agents.
- Stack: Python, SQLite, Telegram, cron. Status: **live**.
